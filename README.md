# Dashboard Akademik

Dashboard Akademik adalah aplikasi web untuk memantau data akademik mahasiswa seperti IPK, IPS, jumlah SKS, transkrip nilai, dan statistik akademik lainnya.  
Aplikasi ini dibuat menggunakan Next.js dan dapat di-deploy menggunakan Vercel.

---

## Fitur Utama

- Dashboard akademik mahasiswa
- Menampilkan IPK dan IPS per semester
- Total SKS lulus dan gagal
- Transkrip nilai
- Statistik nilai mahasiswa
- Export data ke PDF
- Tampilan responsive
- CRUD data akademik

---

## Teknologi yang Digunakan

- Next.js
- React.js
- Tailwind CSS
- JavaScript
- Supabase / MySQL
- jsPDF

## Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/naufalanabil/dashboard-akademik.git
2. Masuk ke Folder Project
cd dashboard-akademik
3. Install Dependencies
npm install
4. Jalankan Project
npm run dev

Project akan berjalan di:

http://localhost:3000
Cara Deploy ke Vercel
1. Push Project ke GitHub
git add .
git commit -m "upload project"
git push origin main
2. Login ke Vercel

Buka website berikut:

https://vercel.com

3. Import Repository GitHub
Klik Add New Project
Pilih repository dashboard-akademik
Klik Deploy
